🍎 リンゴループ攻略法原因別の診断と対処フロー

リンゴループの3つの原因と、それぞれの対処法を順番に解説します

1️⃣ ソフトウェアの不具合

よくある原因

  • PCにつないでアップデート中やバックアップ中にケーブルを抜いてしまった、または何らかの原因で失敗した
  • 夜間に自動アップデートがはじまったが通信環境の不具合などで失敗した
  • 容量がいっぱいのまま使い続けていたせいでOSの読み込みに不具合が出た（iOS13でよくある）
  • その他、何らかの原因でOSが正常起動できなかった

対処フロー

  1. PC（iTunes）につないでiPhoneをリカバリーモードに入れる
  2. まずはデータが残せるように「アップデート」（OSの更新）を試す
  3. アップデートが失敗する場合 → エラーコードを確認（下表参照）
  4. データが不要なら「復元」（初期化）を試す
  5. それでも失敗する場合 → DFUモードに入れて復元

よく出るエラーコードと対処法

エラー意味・対処
4013、13基板破損の可能性大。初期化でもほぼ復元不可。
9初期化で改善の可能性あり。基板破損の場合も。
78初期化で改善の可能性大。
14、4005パーツの破損の影響でアップデートできていない可能性。データを残したいなら疑わしいパーツを外してアップデート。初期化ならほぼ改善。
容量いっぱいで使っていた場合は初期化でしか改善しません。

2️⃣ 各種パーツの破損

iPhoneは起動時にすべてのパーツが正常に動くかどうか読み込みに行くので、破損パーツがあるとエラーを吐いてリンゴループになります。

「バッテリーが弱っているとなる」と説明する業者が多いですが、バッテリーだけでなく近接、ドック、画面、電源・ボリュームケーブル、リアカメラなど、コネクタで基板につながったパーツはすべて原因になりえます。

対処法

破損していると思われるパーツのコネクタを外して起動させてみる。
例：近接を外して正常起動すれば近接が原因、ドックを外して起動すればドックが原因。
ひとつひとつパーツを外してチェックし、原因がわかればそれを交換すればOK。

チェック順序（効率的な順番）

  1. 近接センサー（最もよく破損）
  2. ドックコネクタ
  3. ホームボタン
  4. バイブレーター（特にX系。ドックと勘違いしやすいので注意）
  5. 電源・ボリュームケーブル
  6. リアカメラ
全てのパーツを試して改善しない場合は、ソフトウェアもしくは基板破損の可能性あり。それぞれの項目の対処法を試してください。

3️⃣ 本体基板の破損

ソフトウェアの不具合、パーツの不具合、両方の対処法を試してダメなら基板破損の可能性大です。

→ 池袋東口店に相談してください。
一度「復元」をかけてしまうと、失敗してもデータは消失している可能性があります。データが目的なら「復元」をかける前に相談しましょう！
